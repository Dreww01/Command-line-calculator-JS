
# 🧮 Command-Line Calculator (Node.js)

A simple command-line calculator built with **Node.js** that supports **two or three-step arithmetic operations** using `+`, `-`, `*`, and `/`.

---

## 📦 Features

- ✅ Handles 2 or 3 numeric inputs
- ✅ Supports `+`, `-`, `*`, and `/` operations
- ✅ Validates user input to avoid errors
- ✅ Detects and prevents division by zero
- ✅ Uses `prompt-sync` for real-time CLI input

---

## 🚀 How to Use

1. Clone or download the repository.
2. Install the required package:

```bash
npm install prompt-sync
````

3. Run the calculator:

```bash
node calculator.js
```

4. Follow the on-screen prompts to:

   * Enter two numbers and an operator
   * Optionally add a third number and second operator

---

## 🔢 Example

```
Enter First number: 10
Enter Second number: 2
Enter first operator (+, -, *, /): *
Would you like to add a third operation? (yes/no): yes
Enter second operator (+, -, *, /): +
Enter Third number: 5

Result of: 10 * 2 + 5 = 25
```

---

## 🛠 Requirements

* Node.js
* [`prompt-sync`](https://www.npmjs.com/package/prompt-sync)
